# Sakai 1.11.1 and the intrinsic strong topology

## Source statement

Sakai Lemma 1.11.1 (printed p. 26, PDF p. 38) fixes a self-adjoint `h` in a W-star
algebra, writes `e(λ)=s((λ1-h)⁺)`, and asserts:

```text
(∀ n, λₙ ≤ λ) → Tendsto λₙ atTop (nhds λ)
  → e(λₙ) → e(λ) in s(M,M_*).
```

It does not assume that the sequence is monotone. The exact source reconstruction and page-level
dependencies are recorded in `SAKAI_1_11_1_SOURCE_AUDIT.md`.

## Meaning of `s(M,M_*)`

The exact Lean realization is the existing type synonym
`Ultraweak.Strong M P`, written `s(M, P)`, where `P` is a specified Banach predual. Its topology is
generated by

```text
Ultraweak.Strong.seminorm φ x
  = √‖φ(toUltraweak (x* x))‖
```

as `φ` ranges over positive ultraweakly continuous complex functionals. This is precisely Sakai's
Definition 1.8.6. The norm around the scalar is harmless: positivity makes `φ(x*x)` a nonnegative
real scalar inside `ℂ`.

Topology ledger:

| Source topology | Lean representation | Relationship used here |
| --- | --- | --- |
| norm | norm topology on `M` | only for scalar-cutoff continuity in the earlier LUB proof |
| strong `s(M,M_*)` | `Ultraweak.Strong M P` | exact conclusion of 1.11.1 |
| strong-star | no new object introduced | not needed |
| weak/ultraweak `σ(M,M_*)` | `Ultraweak M P` | intermediate monotone projection convergence |

The proof uses a new projection-specific implication

```text
eventually pᵢ ≤ q  and  pᵢ → q ultraweakly
  ⇒
pᵢ → q strongly.
```

No boundedness hypothesis is missing: domination by the fixed projection supplies the exact
projection identity needed by every strong seminorm. The already established continuous identity
map gives strong-to-ultraweak convergence for arbitrary nets; the converse is asserted here only
under this projection/order hypothesis.

## Library audit

- **Sak-AI:** `Ultraweak.Strong`, its seminorm family, `WithSeminorms` convergence criterion, the
  specified-ultraweak projection lattice, support projections, and ultraweak monotone convergence
  were already available.
- **Pinned Mathlib** (`476ab284693e554a6b48c5f5210cb4fb5ae51252`): supplies the locally convex
  seminorm framework and projection order identities, but no intrinsic W-star strong topology or
  this projection convergence theorem.
- **Audited current Mathlib:** no equivalent intrinsic predual-indexed strong topology or
  projection convergence API was found. This remains a plausible future upstreaming area.
- **Original LeanOA:** no equivalent implementation was found.

No second strong topology and no concrete strong-operator-topology wrapper was introduced.

## Proof architecture

1. For `pᵢ ≤ q`, the difference `q-pᵢ` is a projection and
   `(pᵢ-q)*(pᵢ-q)=q-pᵢ`.
2. Ultraweak convergence therefore makes every scalar `φ(q-pᵢ)` tend to zero, which is exactly
   strong convergence after square root.
3. The existing monotone spectral theorem plus this projection upgrade gives strong convergence
   along any monotone cofinal cut net.
4. For an arbitrary filter approaching `r` from below, choose a strictly increasing real sequence
   `g n → r`. For each strong seminorm, one `g n` is close enough. Eventually
   `g n ≤ f i ≤ r`; nested-projection seminorm monotonicity supplies the squeeze.

This route is independent of any PVM or integral and keeps Mathlib CFC canonical.

## Relation to existing spectral results

- The old `tendsto_spectralProjectionIio_of_monotone` remains a useful ultraweak directed-net
  theorem, but is no longer labeled as the exact source lemma.
- Sakai 1.11.1 is now **SOURCE-FORMALIZED** in the correct strong topology.
- Strong convergence implies the previously documented ultraweak consequence via the existing
  continuous comparison map.
- Spectral bands, finite sums, tagged sums, and truncated-affine CFC recovery are unchanged.
- A future PVM can reuse the projection-LUB and nested-seminorm API; nothing is hardwired into a
  new spectral-family structure.
