## 1. Sakai's sigma-WOT definition

### Source convention

**SOURCE-CHECKED.** Section 1.15 begins on printed page 33 (PDF page
45). Sakai fixes a complex Hilbert space \(H\), writes \(B(H)\) for its bounded
operators, and fixes the adjoint convention

\[
(a\xi,\eta)=(\xi,a^*\eta).
\]

Thus Sakai's scalar product is linear in its first argument. Mathlib's inner
product is conjugate-linear in its first argument and linear in its second.
Consequently the source coefficient

\[
\omega_{\xi,\eta}(T)=(T\xi,\eta)_{\mathrm{Sakai}}
\]

is represented in Mathlib by

```lean
⟪η, T ξ⟫_ℂ
```

and is complex-linear in `T` and `ξ`, conjugate-linear in `η`.

### WOT and sigma-WOT

**SOURCE-CHECKED.** On printed page 34 (PDF page 46), WOT is generated by

\[
T\longmapsto |(T\xi,\eta)|,\qquad \xi,\eta\in H.
\]

The sigma-weak operator topology is generated by

\[
T\longmapsto
\left|\sum_{n=1}^{\infty}(T\xi_n,\eta_n)\right|
\]

where the two sequences satisfy the **separate** conditions

\[
\sum_n\lVert\xi_n\rVert^2<\infty,
\qquad
\sum_n\lVert\eta_n\rVert^2<\infty.
\]

Sakai does not use one joint summability hypothesis, and he does not restrict
the topology to a bounded subset of \(B(H)\).

On the same page, Sakai lets \(V\) be the linear space of all WOT-continuous
linear functionals on \(B(H)\), identifies WOT with
\(\sigma(B(H),V)\), and defines \(B(H)_*\) to be the norm completion
\(\overline V\). His argument first establishes that the dual of
\(\overline V\) is \(B(H)\). Trace-class operators are introduced only
after Propositions 1.15.1 and 1.15.2, and are identified with this predual in
Theorem 1.15.3 on printed page 39 (PDF page 51).

### Invariance formulas

The source proof of Proposition 1.15.1, on printed page 35 (PDF page 47), says
that \(V\) is norm-dense, self-adjoint, and invariant. The inspected passage
does not print the coefficient-level formulas. With the source convention they
are the following elementary derived identities:

\[
\omega_{\xi,\eta}(aT)=\omega_{\xi,a^*\eta}(T),
\qquad
\omega_{\xi,\eta}(Ta)=\omega_{a\xi,\eta}(T),
\]

and, for \(\varphi^*(T)=\overline{\varphi(T^*)}\),

\[
\omega_{\xi,\eta}^*=\omega_{\eta,\xi}.
\]

These formulas are mathematical derivations, not quotations and not claims
about declarations already integrated in Sak-AI.

## 2. Square-summable coefficient-series semantics

The closest existing Lean carrier for the source data is, schematically,

```lean
ξ η : lp (fun _ : ℕ => H) 2
```

and the source series is

```lean
∑' n, ⟪η n, T (ξ n)⟫_ℂ
```

for `T : H →L[ℂ] H`. Mathlib's `lp.summable_inner` and
`lp.hasSum_inner` provide the Hilbert-space Cauchy--Schwarz summability
engine. One must still map the `ξ` sequence coordinatewise by `T` and verify
the scalar-linearity conventions when bundling the result as a continuous
linear functional of `T`.

For partial sums

\[
f_m(T)=\sum_{n=1}^{m}(T\xi_n,\eta_n),
\]

Sakai's exact estimate on printed page 35 is

\[
|f(T)-f_m(T)|
\leq \lVert T\rVert
 \left(\sum_{n>m}\lVert\xi_n\rVert^2\right)^{1/2}
 \left(\sum_{n>m}\lVert\eta_n\rVert^2\right)^{1/2}.
\]

It has two immediate formal consequences.

1. Each such series defines a norm-continuous functional on `B(H)`.
2. Its finite partial sums belong to the finite coefficient span \(V\), so
   the series functional belongs to the norm closure \(\overline V\).

These consequences would prove

\[
\text{sigma-WOT}\ \leq\ \sigma(B(H),\overline V)
\]

in Sakai's ordering of topologies. They do **not** prove the reverse
comparison. Defining the predual as the norm closure of finite coefficients
does not by itself prove that every element of that closure has a single
two-sequence representation. That representation is Sakai Corollary 1.15.5
and depends in the source on the trace-class identification and functional
polar decomposition.

Sak-AI's `LeanOA/Lp/Holder.lean` contains `lp.holderL` and
`lp.dualPairing`. They are useful for estimates and summation, but
`lp.dualPairing` is bilinear in its two displayed inputs. The coefficient
pairing is conjugate-linear in `η`, so an explicit semilinear/Riesz bridge is
still required; this is not a ready-made sigma-WOT functional.

## 5. Trace-class availability and cost

### Source object

**SOURCE-CHECKED.** On printed page 36 (PDF page 48), Sakai defines a bounded
operator \(a\) to be trace class when

\[
\operatorname{Tr}(|a|)<\infty.
\]

He proves that trace-class operators are exactly products of two
Hilbert--Schmidt operators. On printed pages 37--38 he proves

\[
\varphi_a(x)=\operatorname{Tr}(xa),
\qquad
\lVert\varphi_a\rVert=\operatorname{Tr}(|a|)=\lVert a\rVert_1,
\]

that trace class is Banach, that finite-rank operators give elements of \(V\),
and that trace class is the norm closure of finite-rank operators. The
rank-one calculation shows that all vector coefficients occur, and Theorem
1.15.3 identifies trace class isometrically with \(B(H)_*\).

### Lean availability

**NOT FOUND BY AUDIT.** Neither pinned/current Mathlib, original LeanOA, nor
current Sak-AI has this infinite-dimensional object or its trace norm. The
available finite-dimensional `LinearMap.trace` is not a substitute.

Building the source trace-class route first would require, at minimum:

- an infinite-dimensional positive trace independent of orthonormal basis;
- Hilbert--Schmidt ideal, norm, completeness, and adjoint/multiplication API;
- factorization of trace class through two Hilbert--Schmidt operators;
- trace cyclicity against bounded operators;
- trace norm, completeness, and finite-rank density;
- sufficient compact positive spectral decomposition.

Mathlib's compact-operator and Hilbert spectral APIs reduce parts of that
work, and Sak-AI's polar-decomposition work is relevant, but the complete route
is much larger than the predual bridge required for Proposition 1.15.1.
Trace class should be formalized later for Theorem 1.15.3, not made an
artificial prerequisite for the earlier proposition.

## 6. Hilbert--Schmidt availability

**SOURCE-CHECKED.** Sakai introduces the Hilbert--Schmidt norm on printed page
35 (PDF page 47), using a complete orthonormal system:

\[
\lVert a\rVert_2^2=\sum_\alpha\lVert a\xi_\alpha\rVert^2.
\]

On printed page 36 he proves basis independence, star invariance, two-sided
ideal estimates, completeness, and compactness.

**NOT FOUND BY AUDIT.** No bundled infinite-dimensional Hilbert--Schmidt
operator space or norm was found in the audited Lean corpora. Mathlib supplies
orthonormal bases, `lp`, infinite sums, compact operators, adjoints, and the
finite-dimensional singular-value API, but these ingredients have not been
assembled into the source object. Finite-dimensional singular values do not
support an arbitrary-Hilbert-space Schatten-2 definition.

This again argues against a Hilbert--Schmidt-first concrete predual.

## 7. Tensor-product possibilities

There is a standard conceptual description

\[
B(H)_*\cong H^*\widehat\otimes_\pi H
\]

through \(f\otimes\xi\mapsto[T\mapsto f(T\xi)]\). Using \(H^*\) rather than
writing a conjugate Hilbert space makes the complex scalar convention
explicit; Riesz then identifies \(H^*\) conjugate-linearly with \(H\).

Pinned and current Mathlib provide enough algebraic tensor and continuous
multilinear infrastructure to state the uncompleted coefficient map. They do
not provide the completed projective tensor product needed for this
identification. A tensor-first route would additionally have to prove:

1. separation of the projective seminorm in this case;
2. the pure-tensor norm equality;
3. completion and the extension universal property;
4. the kernel/quotient statement for the coefficient map;
5. reflexive/Riesz recovery identifying the dual with `B(H)`.

The ordinary inner-product tensor file is not a replacement: its norm is the
Hilbert tensor norm, not the projective/nuclear norm relevant to trace class.

**Recommendation:** do not use the tensor route for the next transaction. It
is clean but presently creates a second major foundation before reaching
Proposition 1.15.1. A future projective-tensor API could later give a more
abstract identification of the same predual.

## 8. Recommended concrete-predual architecture

### Carrier

The coefficient workstream supplies the finite coefficient span

```lean
V_H : Submodule ℂ (StrongDual ℂ (H →L[ℂ] H))
```

with coefficient, exact norm, star, left/right invariance, separation, and WOT
identification lemmas. These declarations are integrated at the more general
`RCLike` / continuous-linear-map level.

Define the predual carrier to be the actual operator-norm closure in the norm
dual:

```lean
P_H := V_H.topologicalClosure
```

viewed as a subtype/closed submodule of
`StrongDual ℂ (H →L[ℂ] H)`. This is preferable to an abstract
`UniformSpace.Completion V_H` because:

- it is exactly Sakai's norm-completion construction;
- its elements remain concrete norm-continuous functionals on `B(H)`;
- completeness follows from the closed-submodule API;
- evaluation is canonical, with no separately chosen extension map;
- the embedded image of `V_H` is dense by construction;
- the later trace-class map has the correct concrete codomain.

The copy of the finite coefficient span inside `P_H` should use the canonical
inclusion into the closure, not a second span.

### Direct conjugate-linear Riesz recovery

The shortest implementation route discovered in this audit does **not** need
Sakai's WOT-compactness/Mackey argument and does not need trace class.

The production theorem is more general than the endomorphism case.  For a
seminormed $`E`, a complete Hilbert space $`F`, and

```lean
g : StrongDual 𝕜 (ContinuousLinearMap.vectorFunctionalClosure
  (𝕜 := 𝕜) (E := E) (F := F))
```

define

\[
L_g(\xi)(\eta)=\overline{g(\omega_{\xi,\eta})}.
\]

The exact coefficient norm formula gives

\[
|L_g(\xi)(\eta)|
\leq \lVert g\rVert\,\lVert\eta\rVert\,\lVert\xi\rVert.
\]

Moreover \(L_g\) is conjugate-linear in \(\xi\) and linear in \(\eta\), so it
can be bundled as

```lean
E →L⋆[𝕜] StrongDual 𝕜 F
```

Composing this with the conjugate-linear inverse
`(InnerProductSpace.toDual 𝕜 F).symm` gives a linear operator $`T_g:E\to F`.
Conjugate symmetry and Fréchet--Riesz give

\[
\langle\eta,T_g\xi\rangle
=g(\omega_{\xi,\eta}).
\]

Thus `g` and evaluation at `T_g` agree on every coefficient, hence on the
finite span, and then on all of `P_H` by density and continuity. This proves
surjectivity of canonical evaluation. The same estimates in both directions
prove isometry.

This proof is **KERNEL-CHECKED / PROVED** in
`LeanOA.Mathlib.Analysis.InnerProductSpace.OperatorPredual`.  It needs no
inner product or completeness on $`E` and no nontriviality assumption.  The
normed-domain specialization is installed as the existing `Predual` class in
`LeanOA.Ultraweak.BoundedOperator`.

This route is preferable to reproducing Sakai's WOT-unit-ball compactness
argument or first constructing trace class/a completed projective tensor
product. Those remain honest fallback routes but introduce much more
infrastructure.

## 9. Exact completion theorem implemented

The canonical map is evaluation:

\[

\]

The kernel-checked endpoint is

        (𝕜 := 𝕜) (E := E) (F := F))

with an application theorem

```lean
ContinuousLinearMap.vectorFunctionalClosureEquivDual_apply_apply (T) (φ) :
  ContinuousLinearMap.vectorFunctionalClosureEquivDual T φ =
    (φ : StrongDual 𝕜 (E →L[𝕜] F)) T
```

The separately named theorem
`vectorFunctionalClosureEvaluation_surjective` makes the hard mathematical
step discoverable. For stable downstream typeclass synthesis, the assembly
layer exposes a short carrier `VectorFunctionalPredual 𝕜 E F` together with
the canonical isometry `vectorFunctionalPredualEquivClosure` to the actual
closure. The resulting instance is

```lean
Predual ℂ (H →L[ℂ] H)
  (ContinuousLinearMap.VectorFunctionalPredual ℂ H H)
```

using `vectorFunctionalPredualEquivDual` as `Predual.equivDual`. This wrapper
does not change the mathematical carrier up to the displayed canonical
linear isometry and introduces no second predual semantics.

The proof exposes reusable pieces:

1. coefficient inclusion into `P_H` and its dense range;
2. evaluation on `P_H` as a continuous linear map;
3. evaluation is an isometry (coefficients are norming);
4. `g` produces the bounded conjugate-linear form
   `vectorFunctionalClosureRecoveryForm g`;
5. two-conjugate-map Riesz recovery `vectorFunctionalClosureRecover g`;
6. recovery on each vector coefficient;
7. recovery on all of `P_H` by density;
8. surjectivity and the final linear isometric equivalence.

The theorem is valid for the zero Hilbert space. The construction does not
add `Nontrivial H`; zero-space branches are needed only where an operator-norm
witness argument chooses a nonzero vector.

This completion theorem was the genuine missing concrete-predual theorem. The
definition of `P_H` alone would have been scaffolding; its predual status is
now justified by the proved surjectivity of evaluation.

## 10. Expected sigma-WOT/predual relation

The final expected theorem is

\[
\text{sigma-WOT}=\sigma(B(H),B(H)_*),
\]

Sakai Corollary 1.15.6. Under the recommended model it becomes

\[
\text{sigma-WOT}=\sigma(B(H),P_H).
\]

This equality is **PROPOSED / UNPROVED** and should be split into two unequal
stages.

### Stage A: enough for Proposition 1.15.1

For every pair of square-summable sequences, construct the series functional,
prove the Cauchy--Schwarz tail estimate, and prove membership in `P_H` as the
norm limit of finite coefficient partial sums. Together with finite-support
sequences this gives

\[
\mathrm{WOT}\leq\mathrm{sigma\text{-}WOT}
\leq\sigma(B(H),P_H).
\]

These are the only sigma-WOT comparisons used in Sakai's proof of Proposition
1.15.1.

### Stage B: later global equality

Prove the representation theorem

```text
φ ∈ P_H
  iff
there exist ξ η : lp (fun _ : ℕ => H) 2 such that
  φ(T) = ∑' n, ⟪η n, T (ξ n)⟫_ℂ for every T.
```

Only this converse shows that every predual seminorm is a concrete sigma-WOT
seminorm. Norm closure alone does not supply the controlled two-sequence
representation. A proof may later use trace class and polar decomposition, as
Sakai does, or a separately proved nuclear/projective coefficient theorem.
Until then, topology equality and Corollary 1.15.6 must remain unclaimed.

No permanent sigma-WOT topology synonym is recommended merely to state Stage
A. First use a seminorm family or convergence/continuity characterization and
introduce a topology-bearing carrier only if the later public API requires it.

## 11. Relative Kaplansky requirement

### Existing theorem and mismatch

Current Sak-AI's

```lean
Ultraweak.kaplansky_density_Sak_1_9_1
```

takes an invariant dense test submodule `V`, a
`NonUnitalStarSubalgebra ℂ M`, and a hypothesis that the subalgebra is dense in
the **whole ambient** test-weak space. It concludes that the subalgebra's
closed unit ball is Mackey-dense in the whole ambient closed unit ball.

Sakai instead starts with \(N\subseteq B(H)\), lets \(N_1\) be its WOT closure,
and uses Kaplansky density for \(N\subseteq N_1\). In general \(N\) is not
WOT-dense in all of \(B(H)\), so the existing theorem cannot be applied merely
with `M := B(H)`.

### Implemented public theorem

Let `testWeakClosure V S` denote the carrier obtained by transporting the
closure of `S` in the weak topology induced by `V` back to `M`. The production
theorem keeps the closure target explicit:

```lean
theorem kaplansky_density_of_testWeakClosure_eq
    {V : Submodule ℂ P}
    (hV : SakaiInvariantTestSpace (M := M) V)
    (S T : NonUnitalStarSubalgebra ℂ M)
    (hST : testWeakClosure (M := M) V (S : Set M) = (T : Set M)) :
    closure
      (ofMackey ⁻¹' ((S : Set M) ∩ Metric.closedBall (0 : M) 1) :
        Set (SakaiMackey (M := M) (⊤ : Submodule ℂ P))) =
    (ofMackey ⁻¹'
      ((T : Set M) ∩ Metric.closedBall (0 : M) 1) :
        Set (SakaiMackey (M := M) (⊤ : Submodule ℂ P)))
```

This signature is **AVAILABLE / KERNEL-CHECKED**. It states both sides inside
the original ambient dual pair and does not force the closure carrier to expose
a second predual publicly. The proof derives norm and ultraweak closedness of
the explicit target from `hST`, performs the Krein--Milman argument in the
target subtype, removes source norm-closedness by a closure reduction, and
uses compatible convex-closure transfer for the Mackey conclusion.

For the concrete coefficient test space,
`testWeakClosure_vectorFunctionalPredualSpan_eq_wotClosure` identifies the
target with ordinary Mathlib WOT closure, and
`kaplansky_density_wotClosure` supplies the resulting bounded-operator
endpoint.

The formal theorem should use the closed unit ball, matching current Sak-AI.
Sakai says “unit sphere” in the inspected prose, but the existing source audit
already flags that terminology and the modern theorem is the closed-ball
statement.

## 12. Coefficient-closure transaction outcome and next bounded transaction
