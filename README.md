# LeanOA

LeanOA formalizes operator-algebra results culminating in the uniqueness of Banach preduals of
W-star algebras. The Lean library, mathematical blueprint, and generated API documentation are
published together for this repository.

- [LeanOA documentation site](https://jonbannon.github.io/LeanOA/)
- [API documentation](https://jonbannon.github.io/LeanOA/docs/)
- [Web blueprint](https://jonbannon.github.io/LeanOA/blueprint/)
- [Blueprint PDF](https://jonbannon.github.io/LeanOA/blueprint.pdf)
- [Blueprint dependency graph](https://jonbannon.github.io/LeanOA/blueprint/dep_graph_document.html)
- [Upstreaming dashboard](https://jonbannon.github.io/LeanOA/upstreaming.html)

The documentation site is generated by the repository's GitHub Actions workflow from the current
Lean sources and blueprint. Local verification uses `lake build`, `lake lint`, and
`leanblueprint all`.
